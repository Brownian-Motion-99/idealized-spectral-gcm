# Betts–Miller validation, 2026-10-05

The implemented `:isca` closure reproduces Isca Simple Betts–Miller's ordinary
column adjustments to roundoff once the LCL interpolation difference is
removed. The checks cover both deep branches and shallow transport. Julia's
conservative handling of exact zero integrals, absent in-domain condensation,
neutral crossings, and a buoyant model top remains intentional.
The reference is Frierson's formulation with the O'Gorman–Schneider
modifications described in the Isca module header.

## Independent reference comparison

The optional harness compiles the local, unmodified Isca
`src/atmos_param/qe_moist_convection/qe_moist_convection.F90` at revision
`5c6d5baf74498c5dce3578e235c5254e6856baf6`. FMS stubs provide file/log support
and matched constants, and a saturation wrapper extracts the Smithsonian
kernel directly from the local Isca source. This avoids mixing saturation-table
error with LCL-table error. It is an isolated double-precision column test,
not a full Isca run.

Constants are `Rd=287.04`, `Rv=461.5`, `kappa=2/7`, `cp=Rd/kappa`, `Lv=2.5e6`,
and `g=9.8`. Both implementations use virtual temperature, RH 0.8, tau 7200 s,
and minimum parcel temperature 173.16 K. Fortran uses a 1 s step, so increments
are numerically equal to rates. Isca's LCL table retains `val_inc=0.01`.
The original source is unchanged; the minimum temperature is selected through
its namelist. Compiler checks include array bounds and invalid/zero/overflow
floating-point traps.

A second reference changes only the LCL lookup and its pressure conversion
to an 80-iteration log-pressure bisection. This is labeled an **exact-LCL
control**, not an unmodified Isca result. Its generated source remains in the
comparison output folder for inspection.

The ensemble has 114 input columns: three earlier fixed fixtures, 96 profiles
from seed 20261005, twelve moist profiles spanning the deep closures, and
three explicit edge columns. Of these, 87 enter the live Isca comparison.
The other 27 dry/edge columns use physical invariants because the original
reference clamps out-of-domain LCLs, has lookup-range limits, and leaves LZB
at zero for buoyancy reaching the model top. Inputs cover uniform, stretched,
and logarithmically spaced pressure grids. None of the expected Fortran
outputs are generated by the Julia convection routine.

Maximum absolute differences across the 87 reference columns:

| Quantity | Unmodified Isca lookup | Exact-LCL control |
|:---|---:|---:|
| Temperature rate, K/s | 1.77e-7 | 1.96e-17 |
| Humidity rate, kg/kg/s | 5.40e-11 | 1.54e-20 |
| Rain rate, kg/m²/s | 1.76e-8 | 8.90e-18 |
| CAPE, J/kg | 0.0492 | 6.10e-11 |
| CIN, J/kg | 0.00302 | 6.57e-12 |

The maximum Julia column moist-enthalpy residual in this reference ensemble
is `8.18e-13 W/m²`; the maximum water/rain residual is
`2.17e-19 kg/m²/s`.

Comparison tolerances scale with floating-point operation and input magnitudes.
For the original lookup, each column's discrepancy is bounded by its measured
difference from the independent exact-LCL control plus roundoff. The utility
exits unsuccessfully for unexplained rate, budget-related scalar, regime, or
buoyancy-limit differences, or absent coverage of either deep branch.

Boundary differences are recorded explicitly. At one thermally stable,
saturated origin, Isca's lookup produces about `3.96e-4 J/kg` artificial CAPE
and `5.25e-10 kg/m²/s` rain; Julia returns zero, as does the exact-LCL control.
Surface-coincident LCLs can differ by one grid index because equivalent
humidity conversions differ by an ULP. Isca also retains roughly `1e-21`
humidity-rate residues in some infeasible shallow adjustments; Julia zeros
them. The classifier treats these as numerical residues using input-scaled
tolerances. It introduces no physical CAPE threshold.

The full machine-readable result, including source hashes, compiler/Julia
versions, per-column differences, and explained boundaries, is stored in
[results_20261005.json](results_20261005.json). Its Julia revision identifies
the base commit; source hashes identify the exact validated files, including
the allocation fix. The fixed Fortran outputs are
in [the ensemble fixture](../fixtures/betts_miller_isca_ensemble.tsv), so normal
tests require neither Isca nor a Fortran compiler.

## Conservation, threading, and coupling

The Julia tests check all 114 inputs with both deep closures and both virtual
temperature settings. For every column they verify finite results, nonnegative
rain, adjustment indices, zero rates above the adjustment, precipitation/water
accounting, and moist-enthalpy conservation. Shallow columns additionally have
zero rain and separately vanishing column moisture and thermal tendencies.
Explicit steps at 600 s, tau/2, and tau remain finite with `0 <= q < 1`.

Mixed grid columns exactly match scalar results and reuse their work buffers.
Separate Julia processes with one and four threads produce identical grid
outputs. The allocation check exposed a boxed pressure variable captured by
the LCL residual function. Renaming that binding leaves arithmetic unchanged
and reduces the measured 30-level shallow-column allocation from 17,840 to
928 bytes; the regression limit is 1,024 bytes after compilation warmup.

Coupling checks use mixed deep/shallow columns at 600 s and tau, startup and
leapfrog intervals, with and without large-scale condensation. They verify
that zero-rain shallow rates are applied, condensation receives the updated
state, bounded substeps apply each rate once, and averaged BM/rain diagnostics
match the accumulated increments. Final water and dry-air budgets use the
updated layer masses after the pressure adjustment. Full condensation heating
is used for these checks. A counterfactual condensation call on the initial
state confirms that process ordering affects the tested outcome.

These establish the intended idealized column physics and its coupling.
They do not establish whole-GCM energy conservation or climate fidelity.
Step 6's multi-day model experiments remain deferred.

The focused BM suite passes 15,024 assertions with one and four Julia threads.
The complete suite passes 15,626 assertions in a disposable copy retaining
all tracked working-tree edits except the pre-existing change to the default SST
amplitude in `Lower_Boundary_Temperature.jl`. In the original working tree,
that change produces three failures in the existing prescribed-temperature
test; every executed BM check passes. The original SST edit and other
unrelated changes were preserved byte for byte and are excluded from this
validation commit.

## Reproduction

From the repository root, with Julia and gfortran installed:

```sh
python3 test/validation/compare_isca.py --isca-root ../Isca \
  --julia /path/to/julia --output /tmp/bm-isca-comparison
julia --project=. test/runtests.jl
```

To intentionally regenerate the independent fixture, append
`--write-fixture test/fixtures/betts_miller_isca_ensemble.tsv` to the comparison
command. Review the report and source hashes before committing fixture updates.
Fixture generation writes only after all reference checks pass.
